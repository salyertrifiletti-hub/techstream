# TechStream — пользовательские инструкции

Сборник пошаговых руководств по работе с диагностической программой **Toyota TechStream** и адаптером **MINI VCI (J2534)**. Каждая процедура оформлена в виде отдельного файла в каталоге [`docs/guides`](docs/guides/).

> ⚠️ **Важно.** Пункты меню и названия параметров незначительно отличаются в зависимости от версии TechStream (8.x–18.x), модели и года выпуска автомобиля. Перед выполнением любой процедуры сверяйтесь с заводской сервисной документацией для вашей модели (EWD/RM).

Полный аннотированный список статей, форумных тем и официальных Toyota TSB — в [`SOURCES.md`](SOURCES.md). Для каждой процедуры там 2–5 ссылок на статьи, где уже есть живые скриншоты интерфейса TechStream и фотографии процедур.

## Как добавлять скриншоты

Файлы инструкций ссылаются на изображения в каталоге [`docs/guides/images/`](docs/guides/images/). Имена уже прописаны в инструкциях — достаточно сохранить скриншот с нужным именем, и он отобразится в документе.

Рекомендуемый формат: **PNG**, ширина 1200–1600 px, без личной информации (VIN, госномер, пробег при желании закрасить).

Подробности — в [`docs/guides/images/README.md`](docs/guides/images/README.md).

## Требования к оборудованию

- Ноутбук с Windows 7/10/11.
- Кабель **MINI VCI J2534** (чип FTDI FT232RL).
- Для автомобиля — исправный **16-контактный OBD-II** разъём.
- Заряженный аккумулятор автомобиля (напряжение не ниже 12.4 В) — многие процедуры прерываются при проседании напряжения.
