# 07. Прокачка тормозов через Active Test (ABS)

**Применяется:** после замены блока ABS, тормозных трубок, при попадании воздуха в контур ABS, когда «классическая» прокачка не даёт результата.
**Время выполнения:** 30–40 минут.
**Нужен помощник.**

> ⚠️ Процедура прогоняет тормозную жидкость через клапаны модуля ABS, которые при обычной прокачке закрыты. Без неё воздух, попавший в блок, не удалить.

---

## Что потребуется

- Канистра свежей тормозной жидкости (DOT-3/4 — по регламенту).
- Прозрачный шланг и ёмкость для сбора старой жидкости.
- Ключ на штуцер прокачки (как правило 8 или 10 мм).
- Помощник (нажимать педаль).

## Шаг 1. Классическая прокачка (подготовка)

Прокачайте контуры в стандартном порядке — **самый дальний суппорт от ГТЦ первым**:

1. Задний правый.
2. Задний левый.
3. Передний правый.
4. Передний левый.

Долейте бачок до **MAX**.

![Порядок прокачки суппортов](images/07-abs-01-sequence.png)

## Шаг 2. Подключитесь к TechStream

[Подключитесь к автомобилю](02-connect-to-vehicle.md), двигатель **заведите** (чтобы не разряжать АКБ при длительной работе насоса ABS).

**System Select** → **Chassis** → **ABS/VSC/TRAC**.

## Шаг 3. Откройте Active Test

Вкладка **Active Test** (внизу слева).

![Вкладка Active Test](images/07-abs-02-tab.png)

Найдите один из пунктов (зависит от модели):

- **ABS Motor Check**.
- **Air Bleeding** / **Brake Bleed Mode**.
- **Solenoid Operation Check**.

## Шаг 4. Прокачка клапанов

Выберите нужный клапан, например **FR Hold** / **FR Release** (передний правый).

![Выбор клапана](images/07-abs-03-valve-select.png)

1. Помощник нажимает педаль тормоза и **удерживает**.
2. Откройте штуцер прокачки на этом же суппорте.
3. В TechStream нажмите **Start** — слышно щелканье клапана.
4. Жидкость с воздухом выходит в прозрачный шланг.
5. Нажмите **Stop**.
6. Закройте штуцер, помощник отпускает педаль.
7. Долейте бачок до **MAX**.

Повторите для каждого контура в порядке: FR → FL → RR → RL (или как указано в сервисной документации для вашей модели).

![Процесс прокачки](images/07-abs-04-process.png)

## Шаг 5. Проверка насоса (Motor Check)

Для прогона жидкости через насос:

1. **Active Test** → **ABS Motor** (или *Pump Motor*).
2. Нажмите **Start** на 3–5 секунд.
3. Слышен гул насоса. Повторите 2–3 раза.
4. Снова пройдитесь по всем штуцерам обычной прокачкой.

![ABS Motor Test](images/07-abs-05-pump.png)

## Шаг 6. Контроль

- Педаль тормоза — **упругая**, не проваливается.
- Лампа **ABS** погасла.
- При экстренном торможении на пустой площадке со скорости ~30 км/ч ABS срабатывает корректно (чувствуется пульсация педали).

---

## Если педаль мягкая

1. Повторите цикл **Motor Check + классическая прокачка**.
2. Проверьте, нет ли подтеканий у штуцеров и шлангов.
3. Убедитесь, что в бачке не было воздуха (уровень не опускался ниже MIN).
4. Проверьте вакуумный усилитель — иногда симптомы схожи.
