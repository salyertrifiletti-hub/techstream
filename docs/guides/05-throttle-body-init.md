# 05. Инициализация дроссельной заслонки

**Применяется:** после чистки/замены дроссельной заслонки, замены ЭБУ двигателя, при плавающих оборотах ХХ.
**Время выполнения:** 5–10 минут.

---

## Что делает процедура

ЭБУ записывает в память новое положение закрытой заслонки. Без этого после чистки часто наблюдаются:
- плавающие или завышенные (900–1300) обороты ХХ;
- рывки при трогании;
- глохнущий на нейтрали двигатель.

## Классический способ (без TechStream)

Toyota рекомендует простой алгоритм — он работает на большинстве моделей:

1. Отсоедините **минусовую** клемму АКБ, подождите **не менее 60 секунд**.
2. Подключите клемму обратно.
3. Включите зажигание **IG-ON** (без запуска двигателя) на **30 секунд**, педаль не трогать.
4. Запустите двигатель, прогрейте до рабочей температуры **без включённого кондиционера и других нагрузок**.
5. Проверьте: обороты ХХ должны стабилизироваться на штатных ~650–750 об/мин.

![Снятие минусовой клеммы](images/05-throttle-01-battery.png)

## Через TechStream

Если метод с клеммой не помог — выполните идентификацию через программу.

### Шаг 1. Подключитесь

[Подключитесь к автомобилю](02-connect-to-vehicle.md), выберите **Engine and ECT**.

### Шаг 2. Сброс ошибок

Перейдите в **Trouble Codes** → **Clear DTC** (см. [инструкцию 03](03-read-clear-dtc.md)).

### Шаг 3. Инициализация

Откройте **Utility** → один из пунктов (зависит от модели):

- **Throttle Body Idle Position Learn**.
- **Throttle Position Reset Memory**.
- **ETCS (Electronic Throttle Control System) Learning**.

![Пункт инициализации дросселя](images/05-throttle-02-utility.png)

Нажмите кнопку → **Next** → подтвердите выполнение.

### Шаг 4. Контроль параметров

В **Data List** посмотрите:

- **Throttle Position Sensor (TPS) %** — на закрытой заслонке 10–15%.
- **Idle Speed** — после прогрева 650–750 об/мин.
- **IAC Duty / ISC Steps** — должны стабилизироваться.

![Data List: TPS и Idle](images/05-throttle-03-data-list.png)

### Шаг 5. Проверка на ходу

Прокатитесь 5–10 минут:
- Проверьте отсутствие рывков при трогании.
- Включите/выключите кондиционер — обороты должны плавно корректироваться.

---

## Возможные проблемы

| Симптом | Возможная причина |
|---------|-------------------|
| Высокие обороты не падают | Подсос воздуха (вакуумные шланги, прокладка впускного коллектора) |
| Обороты скачут | Неисправный датчик ТРS, грязный РХХ |
| После чистки заслонки — не заводится | Повреждены контакты разъёма, окислились после мойки |
