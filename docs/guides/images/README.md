# Скриншоты и иллюстрации

В каталоге два типа изображений:

1. **Готовые SVG-схемы** (`*.svg`) — оригинальные векторные иллюстрации интерфейса TechStream, схемы OBD-разъёма, порядка прокачки тормозов и цикла обкатки АКПП. Их можно использовать «как есть».
2. **Места под реальные скриншоты** (`*.png`, пока не вложены) — названия уже прописаны в инструкциях. Чтобы иллюстрация появилась, сохраните скриншот под нужным именем.

> ⚠️ Копировать и распространять оригинальные скриншоты из Toyota TechStream (а также из сервисных мануалов Toyota) без лицензии нельзя. SVG-мокапы в этом репозитории — оригинальные, схематичные, не являются точной копией интерфейса.

## Правила именования

```
<номер_инструкции>-<короткий_код>-<номер_шага>-<описание>.png
```

Примеры:
- `01-install-01-setup-wizard.png` — мастер установки TechStream.
- `04-at-03-reset-memory.png` — пункт меню «Reset Memory» в разделе АКПП.

## Технические требования

| Параметр | Значение |
|----------|----------|
| Формат | PNG (предпочтительно) или JPG |
| Ширина | 1200–1600 px |
| Размер файла | до 500 КБ |
| Содержимое | Без VIN, госномера, персональных данных |

## Как снять скриншот в TechStream

**Windows:** `Win + Shift + S` → выделить область → сохранить `Ctrl + V` в графический редактор или `Win + Print Screen` (сохранится в `Изображения/Снимки экрана`).

## Фотографии подкапотного пространства / OBD-разъёма

Снимайте при хорошем освещении, без вспышки в упор. Фокус — на разъёме/метке, которая упомянута в инструкции.
